# Harsha Maddipudi Portfolio

Complete static website source with the current approved artwork and assets.

## Preview
Open index.html in a browser, or run:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Edit
- index.html: page content and navigation behavior
- assets/style.css: styles and responsive layout
- assets/platform-art.webp: header artwork
- assets/icon-*.svg: vector skill icons
- assets/Harsha-Maddipudi-Resume.docx: downloadable resume

No dependency installation or build step is required. Deploy this folder to any static website host.
